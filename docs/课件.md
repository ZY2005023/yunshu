## 二、情绪状态体系（emotion_diary.dominant_emotion）

十级情绪：`绝望崩溃` → `消沉抑郁` → `焦虑烦躁` → `低落不悦` → `平静淡然` → `轻松惬意` → `愉悦舒心` → `欢欣满足` → `兴奋欣喜` → `极致幸福`

AI 可识别的情绪枚举：快乐 / 平静 / 兴奋 / 满足 / 愤怒 / 悲伤 / 焦虑 / 恐惧 / 沮丧 / 压力

## 三、风险等级（数据分析 / 会话情绪分析）

| riskLevel | 含义 | UI 颜色语义 |
|---|---|---|
| 0 | 正常 | success（绿） |
| 1 | 关注 | info（灰） |
| 2 | 预警 | warning（黄） |
| 3 | 危机 | danger（红） |

情绪评分颜色分界：`>=80` 红、`>=60` 黄、`>=40` 灰、其余绿。

## 四、/data-analytics/overview 响应字段契约

### systemOverview（系统总览卡片）
- `totalUsers` 用户总数
- `totalDiaries` 日记总数
- `totalSessions` 咨询会话总数

### consultationStats（咨询统计）
- `totalSessions` 会话总数（及其他统计字段）

### dailyTrend（近 N 天趋势，数组，用于柱状图）
- `date` 日期
- `sessionCount` 当日会话数
- `userCount` 当日参与用户数

### trendData（情绪趋势，数组，用于折线图）
- `date` 日期
- `avgMoodScore` 当日平均情绪评分
- `recordCount` 当日日记记录数

### activityData（用户活跃度，数组，用于折线图）
- `date` 日期
- `activeUsers` 活跃用户
- `newUsers` 新增用户
- `diaryUsers` 写日记用户
- `consultationUsers` 咨询用户

## 五、前端通用工具逻辑（响应消费约定）

- 统一响应封装：`{ code, msg, data }`，`code === "200"` 为成功
- 分页响应：`{ records: [...], total: n }`
- 文章内容渲染前需 HTML 清理：`\n → <br>`、`**x** → <strong>`、`*x* → <em>`
