# 前端改版需求清单（用户提出，待实现）

> 提出于 2026-09-30，针对心理健康助手前端（Vue3 工程）

## 1. 未登录状态：精简导航
- 未登录时导航栏只显示【首页】+【登录/注册按钮】
- 隐藏：AI 咨询、情绪日记、知识库入口（未登录看不到也用不了）

## 2. 未登录点击功能 → 引导登录 → 回到原页面
- 未登录点击"开始倾诉"（/consultation）和"记录心情"（/emotion-diary）时
- 跳转到登录页，并携带 redirect 参数
- 登录成功后**返回到原本要去的页面**（而不是固定跳首页）

## 3. 登录后去掉"首页"
- 登录状态下首页没有存在意义（营销页性质）
- 登录后导航去掉【首页】，登录后直接进功能页

## 4. 个人中心丰富化
- 现状：只有"退出登录"一个功能，太单调
- 需要补充：用户信息展示（头像/昵称/邮箱）、我的日记入口、我的会话记录入口等

## 5. AI 咨询单页化
- 会话列表和对话窗口整合到**同一个页面**内
- 现状：两者分离，体验割裂

## 6. 会话列表支持点击回到历史会话
- 点击历史会话 → 加载该会话的全部历史消息到对话窗口
- 接口已就绪：GET /psychological-chat/sessions/{sessionId}/messages
- 前端当前不支持点击加载

## 附：情绪花园功能说明（已查明，非缺陷）

位置：AI 咨询页右侧侧栏卡片（consultation.vue）

作用：**当前会话的实时情绪监测仪表**
- 展示当前会话的 AI 情绪分析结论：情绪名称（中性/开心/焦虑…）、情绪评分（0-100）
- 是否负面情绪、风险等级（正常/关注/预警/危机）
- 负面情绪时展示温暖建议卡片（AI 生成）

数据来源：`GET /psychological-chat/session/{sessionId}/emotion`（每轮对话后 AI 分析会话内容并更新）

设计意图：聊天过程中实时监测用户心理状态，负面情绪加重时给出关怀提示——是本系统"心理危机预警"能力的可视化前端。
